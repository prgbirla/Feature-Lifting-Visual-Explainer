Machine Learning · Feature Lifting

How does a classifier decide where one class ends and another begins?

A classification model analyzes data to find the patterns that mark which class it belongs to. But how does a model find the cutoff for a class when data can vary so greatly?

Section 1Decision Boundaries

Let’s look at a simple example.

Let's say we have a dataset which contains many points with two features: x1 and x2. Each data point also has an output value. When graphing the data (with x2 shown as the y-axis), we can choose to display the output values using the shape of each point (one type of output or class is marked with a triangle and the other with a star). A good model will realize the triangles and stars can be separated with a line. This line is a boundary between the classes, called the decision boundary.

When a new data point is entered to the model, its values for x1 and x2 are checked against the decision boundary. In this case, if the point falls on the graph to the left/above the boundary on the graph, the model predicts "triangle". Otherwise, it predicts "star".

Section 2Linear Classifiers

For a model, finding a decision boundary means optimizing the parameters of an equation. The human, visual answer is not scalable, and hence not usable for most applications.

For finding the best linear boundary, the model optimizes the parameters of y and m in y = m0 + m1x1 + m2x2 + …, where the equation continues with each feature shown as x, and an m value associated with each.

Without the linear requirement, the equation can be far more complicated, with many more parameters and possibilities to test for. Some examples of nonlinear equations are below. Consider how many possibilities a model would have to test to land on one of these possibilities, and the added amount of time, energy, and effort that would take in comparison to only checking linear possibilities.

y = x1 + x23
y = x1x2
y = 1 / (1 + ex1x2)

Examples of nonlinear decision boundaries.

There is another downside to nonlinear models: they can have relatively “lumpy” loss landscapes. It's harder to navigate (possibly with more local minimums where a model could get stuck) which makes it harder to find the optimum model parameters. A linear boundary equation means a simpler-to-optimize landscape (a more optimum optimization process!).

In the end, a linear function limitation to decision boundaries is less computationally expensive and time consuming. A classifier with that limitation is a linear classifier.

Section 3What if you can’t?

Sometimes a linear boundary doesn't seem like the best idea. In fact, looking at the next dataset's graph, we can see that a line would an abysmal idea. It would make a lot of errors... whereas a circle might just work.

So, the model does something counterintuitive to our previous discussion on decreasing complexity: it increases the computational complexity by increasing the dimensions.

The reasons why we choose to do this will become clear in a moment. For now, try to understand that increasing dimensions and keeping the linear limitation can be much nicer than removing the nonlinear requirement in fewer dimensions, both in terms of computational cost and the loss landscape. Let’s try it.

Section 4Feature Lifting

We may have agreed to add dimensions, but now we need to decide where it comes from - dimensions can't be added by magic. Each one is supposed to represent a feature of the data. So, to stay true to the original data, new features must be built from the original ones. x3 (think z on an xyz-graph) has to be some combination of x1 and x2.

The boundary we want is a circle around the origin - which marks a set distance from the origin. Using this information, we can manually define x3 = √(x12 + x22) so that our new feature is defined by the original features and the new feature shows the distance for each data point from the origin.

In the 3-D graph above, the triangles and stars are in the same locations in regard to an xy-graph, but now hold a z-value which raises them based on their distance to the origin. What’s fascinating is how well a linear boundary works now. x3 = 6 is a flat slice that cleanly separates the two categories. We have achieved a linear decision boundary!

Section 5Are we sure?

That’s a little confusing, so let’s step away from the dataset for a second. Let's graph x3 for all of the x1 and x2 values, not just the data points. The function creates a cone-like shape.

Our suggested slice of x3 = 6 cuts through it. Since x3 represents the distance to the origin, the linear slice marks every spot on the xy- or x1x2-grid that is 6 units from the origin. This is our decision boundary.

Marking points that are 6 units away matches our understanding of a circle, which is what we visually expected for this dataset, and sure enough, the points where the cone and linear slice meet create a circle. Notice that the decision to define x3 by the distance formula was key to the result.

Removing x3 but keeping the cone-slice intersection shows the circle clearly. Returning to our dataset, we can confirm this circle shape works for separating the triangle and star classes.

A linear answer in 3-D has become the nonlinear answer in 2-D that the dataset needed.

Now let’s confirm how helpful feature lifting was. Below are (hypothetical but realistic) loss landscapes for the 2-D nonlinear problem and the 3-D linear one. Recall that the model doesn't get to see the full landscape immediately, it only sees the current value and slope. On the lumpy landscape, the model can easily convince itself it has reached its final point when it hasn’t. The smooth one is far easier to navigate.

Section 6Again!

Here is another dataset, this time with three classes shown as triangles, stars, and squares. In 2-D, no straight line can accurately separate them. The classes sit in sections better described as curved bands.

The model then analyzes the dataset and runs through a polynomial kernel of possibilities for the x3 dimension equation (which includes versions of 1, √2 x1, √2 x2, √2 x1x2, x12, x22). In this case, our model ran different scenarios and chose x3 = −x12 + x2. It then looked for linear planes to define the boundaries between the classes and optimized them by their loss landscape. The result is x3 = 1.2x1 + 0.05x2 + 2 and x3 = −0.9x1 + 0.15x2 − 10.

Both slices are (linear) planes in 3-D, so even this larger problem can be handled by a linear classifier. Back in 2-D, we get the corresponding nonlinear boundaries (nonlinear for 2-D).

Section 7To Summarize

  • A decision boundary is the cutoff where a classifier switches from one class to another.
  • Linear classifiers are restricted to linear boundaries, since nonlinear options can be more costly and be harder to optimize.
  • When no line fits the restrictions and separates the data with an appropriate level of accuracy, feature lifting adds dimensions built from the original features, and possibly meant to highlight some pattern in the data.
  • A linear boundary in the higher-dimensional space can appear nonlinear when brought back to the original features.
